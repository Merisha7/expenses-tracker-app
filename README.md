# Expense Tracker System

A collaborative web-based Expense Tracker application developed for the Collaborative Development Module.

## Project Overview

The Expense Tracker System helps users manage personal finances by tracking income, expenses, savings goals, and financial activities through an organized dashboard interface.

## Features

- User Registration & Login
- OTP Email Verification
- Forgot Password System
- Dashboard Overview
- Income & Expense Management
- Savings Goals Tracking
- Graph & Chart Visualization
- Calendar Feature
- Edit/Delete Records
- Push Notifications
- Responsive User Interface
